# Wency & Clea — Wedding Invitation

A responsive, formal navy-blue and gray wedding invitation website with an animated envelope, clickable wax seal, RSVP interaction, and wedding palette.

## Preview locally
Open `index.html` in your browser. Internet is only needed for the Google Fonts; fallback fonts are included.

## Publish with GitHub Pages
1. Create a new repository on GitHub (for example, `wency-clea-invitation`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait a minute or two and open the published URL shown in the Pages section.

## Customize before publishing
Search and replace these placeholders in `index.html`:
- `April 00, 2027` — replace with the confirmed date.
- `TIME TO BE ANNOUNCED` — add the ceremony time.
- `Venue to be announced` — add the reception venue.
- Add an RSVP deadline/contact details if needed.

The “Yes” button dodges up to five times, then stays still so guests can click it. The “No” button shows a playful joke. This is a visual/demo RSVP only; it does not collect or send guest responses to you.
